BREAKING (pre-1.0): `createSchema<Ctx, Resolvers>()` now refuses a resolver map whose context does not match `Ctx`: a `Resolvers<Other>` generated by graphql-codegen (or any map whose field resolvers expect another context) is a type error on `resolvers`, where it used to compile. Graphql-codegen's `typescript` and `typescript-resolvers` output is compiled against graxia in its tests, and a new Codegen guide covers `contextType` with `InferContext`, mappers and `enumValues`. Migration: a `Resolvers` generated for another context: point codegen's `contextType` at your `InferContext` type and regenerate; see the Codegen guide.
