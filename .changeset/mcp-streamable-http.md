"@graxia/mcp": minor
---

First public release of `@graxia/mcp`: `createMcp(graxia, { name })`, a stateless Streamable HTTP MCP server on the Web `Request`/`Response` pair (the schema and the body limit come from `graxia.schema` and `graxia.limits`), with the tools `graphql_schema` (overview, `types`, `search`), `graphql_query` and, with `mutations: true`, `graphql_mutate`. Operations are validated against the schema the caller may see (`can`; introspection is refused) and run through `graxia.execute`, whose codes and fixes reach the agent. DNS-rebinding guard (`Origin` and `Host`, `allowedHosts`), CORS for `allowedOrigins`, a body size cap, `onError`, and a `fix` on every refusal.

OAuth resource server: `auth: { resource, authorizationServers, verifyToken }` makes every request need a bearer token with `mcp:read` (401 and 403 `WWW-Authenticate` challenges with `resource_metadata`, an `access_token` in the query refused, expiry and audience checked: a token whose info has no `audience` is refused unless `auth.audience: 'verifier'`; a verifier that throws is a 503 with `Retry-After`, and it may resolve its own `Response`; Bearer only, no DPoP), `graphql_mutate` listed and callable only with `mcp:write` (a read-only call is a 403 step-up when `mutations` is on), the RFC 9728 metadata at `mcp.metadataPath` (`mcp.metadata`; typed `string` when `auth` is passed), the verified token as `can`'s third argument and `mcpAuth()` for graxia's `context` builder. New codes `MCP_UNAUTHORIZED`, `MCP_INSUFFICIENT_SCOPE` and `MCP_TOKEN_IN_URL`.

Persisted operations as typed tools: `operations: { documents, include?, descriptions? }` takes core's `TrustedManifest` (codegen or Relay object, Apollo manifest, `Map`) and makes each named query, and each mutation with `mutations: true`, one tool (`BookById` is `book_by_id`) with a JSON Schema 2020-12 input built from its variables (scalars, enums, lists, input objects through `$defs`, `@oneOf`, defaults, `@constraint`) and an output schema built from its selection set. A description is required (the operation's own, or `descriptions`); `createMcp` throws one `GraxiaConfigError` listing every problem with its fix. The tools run through `graxia.execute`, so they work with trusted documents in `strict` mode; a tool is listed only when its operation is valid in the caller's view, and a mutation tool needs the write scope. `genericTools: false` keeps only `graphql_schema` and the typed tools. New types `McpOperationsOptions` and `McpOperationInfo`.
