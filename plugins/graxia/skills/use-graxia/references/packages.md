| `@graxia/core`     | 0.4.0 (breaking, pre-1.0: see `node_modules/@graxia/core/docs/guide/pubsub.md#migrating-from-03` and `docs/guide/telemetry.md#migrating-from-opentelemetryapi`): plugins, GraphQL over HTTP, SSE and WebSocket subscriptions, `@defer` / `@stream`, typed PubSub and `KeyValueCache`, context and cancellation (`InferContext` writes the context once; `createGraxia` checks it against `createSchema<Ctx>` at compile time; graphql-codegen's `Resolvers` goes as `createSchema<Ctx, Resolvers>()`'s second generic, `contextType` pointing at the `InferContext` type, and a map for another context is a type error), errors and masking, `execute` and a test client (`graxia.schema` and `graxia.limits` expose the schema and the body and token limits in force); secure by default (CSRF header, WebSocket `Origin` check, introspection and suggestions off in production), operation limits and `@cost` / `@listSize`, trusted documents and APQ, `fieldRateLimit`, `@graxia/core/agent` (descriptive `@needs` / `@constraint` / `@errors`, `printSchemaFor` and `visibleSchema` for the schema one caller may see, `lintDescriptions`, readers; every graxia error carries `extensions.fix`), spans on `@softistx/telemetry` (optional peer) |

| `@graxia/mcp`      | 0.1.0 (first publish pending): `createMcp(graxia, { name })`, stateless Streamable HTTP MCP server; tools `graphql_schema`, `graphql_query`, `graphql_mutate` (`mutations: true`); OAuth resource server with `auth` (`metadata`, `metadataPath`, scopes, `mcpAuth()`), `can(request, ctx, auth)` for the caller's view, Origin and Host checks, CORS; `operations: { documents: manifest }` makes each persisted operation a typed tool (`BookById` → `book_by_id`, input and output JSON Schemas, description required, works under strict trusted documents), `genericTools: false` keeps only those and `graphql_schema`; docs in `node_modules/@graxia/mcp/docs/`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
